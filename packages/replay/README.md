# @recurr-dev/replay

Recurr replay orchestrator — reconstructs a captured execution in an isolated child process (loopback-only listeners, instrumented egress served from the record, blocked subprocesses/workers/raw sockets) and diffs it against the original.

Part of the [Recurr](../../README.md) monorepo — see the root README for the
workflow, security model, compatibility matrix, and development setup.
