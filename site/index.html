The bug happened in production.
Replay it on your machine.

Recurr captures real production executions — HTTP in, dependencies out, errors, time — into incident records, then reconstructs and replays them deterministically on your machine. Diff the replay against the original; save the fix as a regression.

# instrument once npm i @recurr-dev/sdk # production incident → record → replay → diff recurr replay RUN-9F3XK2 --cmd "node dist/index.js" ✓ outcome reproduced · 1 divergence (remoteAddr)

How it works

captureSDK middleware records the request, outbound calls, db queries, errors — secrets redacted before they hit disk.
replayThe CLI re-runs your entrypoint in an isolated process: recorded responses served back, time and randomness pinned to the original.
diffObserved status and side-effects are compared to the recorded incident — divergences reported field by field.
regressionSave the incident as a scenario; re-run it after the fix. fixed: true when the outcome stops matching.

What's in the box

  • Capture SDK — express/fastify/koa/raw-node middleware; patches fetch, http.request, clock, and PRNG outside the request context.
  • Deterministic replay — AsyncLocalStorage-scoped; replay mode forces loopback listeners and serves all instrumented egress from the record. Never dials production.
  • Sandboxed child — env sanitizer strips keys/tokens/DSNs/proxies/cloud creds; child_process, workers, dgram, raw sockets, and native addons are refused at the module boundary.
  • Static preflight — unreplayable targets (framework launchers, blocked-builtin imports) fail in milliseconds, before the child spawns.
  • recurr doctor — init-time warning when your runtime can capture but never replay; tells you why and what to change.
  • Stores — filesystem (fs:), Postgres (pg:), or remote collector (http:) with optional bearer auth.
  • CLI + UI — recurr list/show/replay/diff/regression/doctor, plus a React incident browser served by the collector.
  • Docker — ghcr.io/ydde21/recurr-server, multi-arch, pg-backed compose file included.

Honest limits

Read before adopting. Replay requires Node ≥ 22.15. Framework-launcher targets (next dev, tsx, vite-node) can't replay — run a plain Node entry or bundle. Fetch-style frameworks (Hono et al.) aren't instrumented yet. Replay is process isolation, not a security sandbox — filesystem stays writable.
